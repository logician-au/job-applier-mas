# Security

## Security Principles

JAMS is designed around a security-first philosophy.

### Core Controls

- Human approval before application submission
- Local-first AI execution
- Browser isolation
- Least-privilege agent permissions
- Secrets stored outside source control
- Prompt injection mitigation
- Job descriptions treated as untrusted input

## Reporting Security Issues

Please do not disclose security issues publicly.

Contact the project maintainer directly.
